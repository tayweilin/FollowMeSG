# FollowMeSG  
### Accessible Navigation for Cognitive & Communication Needs

Independence for travelers. Peace of mind for caregivers.

---

## 🧠 Overview

FollowMeSG is a specialised navigation web application designed to improve public transport accessibility for individuals with cognitive and communication needs.

Public transport systems are often complex, crowded, and heavily dependent on text-heavy instructions and audio announcements. For individuals with intellectual disabilities, autism spectrum disorder, early-onset dementia, or non-verbal communication needs, this can result in:

- Disorientation  
- Sensory overload  
- Anxiety  
- Boarding the wrong bus/train  
- Missing the correct stop  
- Increased caregiver stress  

FollowMeSG redesigns navigation around cognitive accessibility rather than expecting users to adapt to complex systems.

---

## 🎯 Target Users

- Persons with Intellectual Disabilities (PWIDs)  
- Individuals on the Autism Spectrum  
- Early-onset Dementia patients  
- Non-verbal individuals  
- Users with cognitive or communication impairments  

---

## 🚍 Problem Statement

Independent travel on public transport is risky and anxiety-inducing for many cognitively and communication-vulnerable individuals.

Research and caregiver feedback highlight key barriers:

- Difficulty boarding the correct bus/train  
- Difficulty alighting at the correct stop  
- Difficulty seeking assistance  
- Overstimulation from crowded environments  

Existing navigation tools are not cognitively accessible and are largely designed for neurotypical users.

---

## 💡 Our Solution

FollowMeSG is a navigation web app built specifically for cognitive and communication accessibility.

Instead of forcing users to adapt to complex systems, we redesign navigation around their needs.

### 🧭 AR Visual Guide
- Stabilised AR compass overlay  
- Clear, visual direction cues  
- Works even when GPS signals are weak  

### 🚦 Overstimulation Prevention
- Real-time crowd load analysis  
- Crowd-aware routing recommendations  
- Visually flags crowded transport services  

### 🔁 Active Caregiver Safety Loop
- Real-time location sharing  
- Deviation alerts when user leaves planned route  
- One-tap caregiver contact  

### 🖐️ Visual & Sign-Friendly Communication
- Visual-first navigation alerts  
- Reduced reliance on audio-only announcements  
- Non-verbal assistance support  

---

## 🛠️ Technology Stack

- Web Application (Frontend)  
- AR-based visual navigation  
- Gyroscope / IMU sensor fusion  
- LTA DataMall API integration  
- Real-time route deviation monitoring  

---

## 🔬 Research Validation

Survey conducted with parents of autistic students from a Singapore special needs school.

Top reported barriers:
- Boarding the wrong bus/train  
- Missing the correct stop  
- Difficulty seeking assistance  

Only a small minority were able to travel independently.

FollowMeSG directly addresses these real-world barriers.

---

## 🏗️ System Flow

1. User selects route  
2. System integrates live transport data  
3. Crowd-aware routing is generated  
4. AR visual guidance is displayed  
5. Continuous route monitoring runs in the background  
6. Caregiver is alerted upon route deviation
